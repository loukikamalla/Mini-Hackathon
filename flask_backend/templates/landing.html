Problem Statement & Solution

Automated Reconciliation of Rice Mill Records with Government Mandi Procurement Data

Currently, rice mills maintain physical registers or Excel sheets while the government issues official OPMS manifests. Manual cross-checking of truck numbers, tare weights, and moisture causes calculation errors and delays in subsidy clearance.

DHANYA is a web application built using Python Flask and Supabase PostgreSQL that automates this entire lifecycle: it ingests multi-format records, identifies discrepancies (moisture cuts >17%, scale variations), computes statutory 67% CMR out-turn quota, and generates official digital Joint Reconciliation Certificates (JRC) for direct subsidy approval.

System Architecture & Tech Stack

🐍 Backend (Python Flask)

Flask 3.0 REST API with Blueprints, handling authentication, automated Excel reconciliation via Pandas, and JRC PDF generation via ReportLab.

⚡ Database (Supabase / Postgres)

PostgreSQL schema with 7 relational tables storing Mandi manifests, inward weighbridge scale data, settlement ledgers, and audit logs.

💻 Frontend (HTML5 & Tailwind)

Clean, lightweight responsive interface without heavy node dependencies, providing role-based views for DCSO and mill operators.
